# 候选知识层

本目录存放任务结束后发现的候选经验、规则、模式和反例。

候选内容还不是正式知识，不能直接当作硬规则使用。

## 使用时机

以下情况可以产出候选知识：

- 同一个问题反复出现。
- 用户明确说“记住”“写进规范”“以后都这样”。
- 任务中发现可复用的方案、流程、风险或反例。
- 事故、缺陷、验证失败暴露出稳定模式。

## 写入要求

候选知识必须包含：

- 来源任务。
- 触发原因。
- 适用范围。
- 证据。
- 建议沉淀位置。
- 是否需要用户确认。

## 审核规则

- `@@X` 负责整理候选。
- `@@TL` 负责判断是否写候选、是否转入正式知识库；转入后用户周审修正。
- 未确认前不得把候选内容写入 `.cursor/rules/`。
- 涉及项目特定经验时，优先放入对应项目档案或项目知识。

## 推荐命名

```text
YYYY-MM-DD-<project-or-topic>-<short-title>.md
```

示例：

```text
2026-10-14-agent-runtime-permission-boundary.md
```
