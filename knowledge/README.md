# 知识库（重构版）

目标：沉淀可复用技术模式，让后续任务能快速检索并复用。

## 结构

- `patterns/`：可复用方案主库（按领域拆分）。
- `decisions/`：关键决策记录（按年份）。
- `incidents/`：事故与高风险事件复盘（按年份）。
- `glossary/`：术语与定义。
- `indexes/`：检索索引（模式索引、标签索引、项目索引）。

## 写入规则

- 正式入库仅在用户明确确认后执行。
- 非确认状态下，先写候选模板，不直接写正式知识条目。

## 查询规则（防大请求）

1. 先查 `indexes/`。
2. 每次最多读取 3 条候选模式（Top-K）。
3. 若仍不足，再扩展查询，不允许全库一次性加载。
