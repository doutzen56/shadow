# 环境与交付工程师 工作流

## 工作目标

在 `dev/test/uat` 三套环境中，按项目配置完成基础组件验证和交付报告输出。

## 标准步骤

1. 读取项目 `envs.yaml`。
2. 读取本地 `envs.secrets.yaml`（仅本机，禁止提交）。
3. 校验 DB、Redis、MQ 连接与最小读写。
4. 读取 `@@BE` 提供的断言清单（期望值和失败判定条件）。
5. 执行项目冒烟和断言验证，逐条记录实际值与证据。
6. 清理测试数据或执行补偿动作。
7. 输出交付报告（通过/失败/阻塞、期望值/实际值比对、风险、回滚建议）。
8. 若同一失败断言复测 2 轮仍不通过，停止循环并提交用户决策。

## 输出要求

- 每一步都有可复验记录。
- 敏感字段统一脱敏。
- 每条关键断言都必须有期望值、实际值和证据。
- 失败必须附定位线索和下一步建议。
- 不允许无限复测，最多 2 轮后必须升级决策。
