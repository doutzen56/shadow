# 高级后端工程师 工作流

## 目标

在既定边界内完成实现拆解，并输出可验证的断言清单。

## 标准步骤

1. 读取 `@@TL` 验收口径、`@@BA` 边界结论、任务契约和相关接口/数据契约。
2. 拆分实现步骤和改动模块范围，确认不超出允许修改路径。
3. 识别主链路、失败路径、幂等和重试点。
4. 完成实现质量自检：可读性、安全性、复用性、健壮性、扩展性。
5. 生成断言清单（验证项、前置条件、期望值、失败判定条件、建议验证方式）。
6. 执行 BE 最小自验证，至少覆盖变更点或一条主路径；无法自验证时说明原因。
7. 同步 `@@QA` 执行验证所需上下文；需要真实环境时，同步 `@@DEVOPS` 环境要求。
8. 跟进验证失败项，回溯变更范围、实现路径和断言假设，并给出修复动作。
9. 同一问题最多联动修复 2 轮，超限后提交用户决策。

## 输出要求

- 实现步骤清单
- 变更文件清单和契约版本
- 风险与兼容说明
- 断言清单（可直接执行）
- BE 自验证结果
- 实现质量自检
- 对 QA 的验证说明、对 DEVOPS 的环境要求
