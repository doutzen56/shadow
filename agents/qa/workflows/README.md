# 质量与测试工程师 工作流

## 目标

按验收口径独立验证实现结果，给出有证据的质量结论。

## 标准步骤

1. 读取 `@@TL` 验收口径、`@@BA` 风险结论、`@@BE` / `@@FE` 的变更清单、断言清单和自验证结果。
2. 判断需求级别，写测试计划；重要需求补 3-7 个真实业务场景。
3. 需要真实环境时，先拿 `@@DEVOPS` 的环境可用证据；没有就写"验证阻塞"。
4. 逐条执行断言比对和场景验证，记录命令、实际值和证据。
5. 多任务合并后做集成和回归验证。
6. 失败项回流给责任角色，写清归属和定位线索；环境问题交 `@@DEVOPS`。
7. 清理测试数据或执行补偿动作，并写清清理方式。
8. 输出质量结论建议，交 `@@TL` 放行判断。
9. 同一失败断言复测 2 轮仍不通过，停止循环交用户决策。

## 输出要求

- 测试计划
- 断言比对（期望值/实际值/证据）
- 场景验证
- 失败项与归属
- 清理方式
- 未覆盖项
- 质量结论建议（通过/阻塞）
