# 团队调度者 工作流

## 目标

把任务稳定路由到 `@@TL`、`@@BA`、`@@BE`、`@@DEVOPS`，形成可执行闭环。

## 标准步骤

1. 识别项目和任务类型。
2. 触发 `@@TL` 确认目标和验收口径。
3. 触发 `@@BA` 输出边界和风险。
4. 触发 `@@BE` 输出实现步骤与验证断言（期望值和失败判定条件）。
5. 触发 `@@DEVOPS` 执行环境验证，并产出断言的期望值/实际值比对结果。
6. 若失败断言存在，触发 `@@BE`/`@@BA` 修复并回到步骤 5（最多 2 轮）。
7. 超过 2 轮仍失败，提交用户决策。
8. 回到 `@@TL` 做最终结论。

## 输出

- 角色协作顺序
- 执行清单
- 风险和阻塞项
- 下一步建议
- 是否触发用户决策
