# 架构决策模板

## 文件开头（frontmatter，原样写在文件最前面）

```yaml
---
id: adr-YYYY-MM-DD-<短名>
title:
doc_type: decision
projects: []
lifecycle_status: candidate / confirmed
confirmed_by: "@@TL" / user
user_reviewed: false
---
```

取值含义见 `config/knowledge-structure.yaml` 的 `knowledge_metadata`。用户说「记一条 ADR」时直接写 `confirmed`、`confirmed_by: user`、`user_reviewed: true`。
