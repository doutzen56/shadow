# 放行判定模板（@@TL）

## 使用时机

- `@@TL` 对本次交付做最终决策时。

说明：该模板服务决策，不替代问题修复流程；失败项必须先经过联动处置。

## 输入材料

- `@@BA`：边界与风险结论
- `@@BE`：断言清单
- `@@DEVOPS`：断言比对报告与证据包
- （可选）`reviewer`：审查问题清单

## 判定结论（必选一项）

- 通过
- 阻塞
- 回滚

## 判定结构

- 结论：
- 判定依据：
- 未闭合风险：
- 必做后续动作：
- 责任角色：
- 截止时间：

## 判定阈值建议

- 满足全部高风险断言且证据完整，可判“通过”。
- 任一高风险断言失败，默认“阻塞”或“回滚”。
- 关键证据缺失，默认“阻塞”。
- 同一问题修复-复测超过 2 轮仍失败，默认转用户决策。

## 输出要求

- 结论必须可追溯到具体证据。
- 不允许只给“主观可上线”描述。
