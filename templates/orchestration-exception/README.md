# 异常调度策略模板（@@X）

## 使用时机

- 角色超时、信息不足、结论冲突、流程中断时。

说明：目标是恢复执行链路并推进问题关闭，不是单独产出异常记录文件。

## 异常类型

1. 信息不足
2. 角色超时
3. 结论冲突
4. 验证阻塞
5. 高风险升级

## 处理流程

### 1) 信息不足

- 动作：列出缺失信息清单并指派补充责任人。
- 升级：超过一次补充仍不足，升级 `@@TL` 裁剪范围。

### 2) 角色超时

- 动作：记录超时节点，临时调整顺序。
- 升级：关键角色超时且影响主链路时，升级 `@@TL`。

### 3) 结论冲突

- 动作：要求冲突方补证据并对齐口径。
- 升级：无法收敛时由 `@@TL` 最终裁决。

### 4) 验证阻塞

- 动作：标记阻塞原因与影响范围。
- 升级：由 `@@BE`/`@@DEVOPS` 给修复时间，`@@TL` 决定继续或回滚。
- 硬阈值：同一问题最多修复-复测 2 轮，超过后必须提交用户决策。

### 5) 高风险升级

- 动作：立即提高优先级，暂停低优先任务。
- 升级：资金、安全、生产影响默认进入 TL 快速决策通道。

## 输出格式

- 异常类型
- 当前状态
- 影响范围
- 临时措施
- 升级对象
- 下一步动作和截止时间
