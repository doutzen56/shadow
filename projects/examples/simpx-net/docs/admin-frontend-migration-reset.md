# Admin 前端迁移纠偏（2026-11-03）

> 结论：当前「菜单全铺壳 + 猜接口」策略失败。表现为空表、错路径、英文字段列、查询条残缺——**看起来有页，实际没有一页达到旧站可用**。  
> 本档覆盖原先「自动连续精修所有叶菜单」的做法。

## 1. 失败根因（不辩解）

1. **横向铺页优先于竖切做通**：133 叶菜单先出 vue 壳，接口按命名猜，未回旧 html 核对。
2. **共用契约没先钉死**：vxe 分页形态、错误提示、查询条布局各页各写，一改百漏。
3. **把「有文件」当成「能用」**：列标题仍是 `UserName`/`CreateAt`，无旧站字段语义。
4. **验收口太松**：没要求「登录后能查到真实数据 + 主操作可点」。

## 2. 新策略（立即执行）

### 2.1 冻结

- **冻结**一切新页脚手架 / 批量生成 / 报表猜路径精修（除下方 P0）。
- 冲突表里「批量生成页 API」状态改为：**壳保留、不算交付**。
- 未进 P0 的页：菜单可留着，但不宣称可用；打开可显示「未验收」空态（可选，后补）。

### 2.2 先做共用壳（一次）

必须先稳定，再写业务页：

| 项 | 要求 |
|----|------|
| 列表请求 | 一律 `adminPost` + `toVxeProxyPage`；禁止再手写 `{page,result}` |
| 失败 | 必须 `ElMessage`；禁止 `catch { return [] }` 静默空表 |
| 查询条 | 统一 `admin-page` 布局类；标签中文；主按钮「查询/重置」 |
| 列 | 标题中文；对齐旧 html 列；禁止裸英文字段名当标题 |
| 枚举/币种 | 见主档 §11：后端 `OldApiEnumDisplay`；前端 `ensureCurrencyEnum`+`formatCurrency`/`formatRealPaidDisplay`；禁止拼 `金额+整型币种`、禁止详情吐 `\|\|` Remark |
| 路径 | 实现前打开旧 html，抄 `searchtableurl` / `url:`，禁止猜 |
| 验收 | 本机登录查到真实行；截图或 curl 记 evidence |

### 2.3 竖切 P0（只做这些，做完再扩）

按旧站日常操作频率，一次只打通一条链路：

| 序 | 页 | 旧 html | 完成定义（DoD） |
|----|----|---------|-----------------|
| 1 | 会员列表 | `user/member/list.html` | 条件查询有数；导出可用；详情/余额可开 |
| 2 | 充值订单 | `money/recharge/order.html` | 列表有数；筛选对齐；导出或审核入口可用 |
| 3 | 提现订单 | `money/withdraw/order.html` | 同上 |
| 4 | 入款审核 | `money/recharge/check.html` | 通过/拒绝真实可用 |
| 5 | 会员帐变 | `report/user/moneylog.html` | `/admin/report/money/log` 有数；列中文 |
| 6 | 银行信息 | `user/member/bank.html` | 列表+审核主流程 |

P0 全部 DoD 过关前：**不新开** game/events/exchange/site 壳页改造。

### 2.4 单页工作法（强制）

1. 打开旧 html，列功能/接口/列/弹层清单（写进页头注释）。  
2. 对照后端路由是否存在；没有先补 Form 接口，不改前端去调 JWT 冒充。  
3. 按共用壳写一页；本机验收。  
4. evidence 记：路径、样例查询、RecordCount。  
5. 冲突表更新：已验 / 部分 / 待拍板。

## 3. 对用户的预期

- 短时间不会「全部菜单都好看」。  
- 会先有 **6 个真能用的页**，其余明确未交付。  
- 比继续铺 100 个空壳更快得到可演示后台。
