# 事故响应

## 目标

先止血、再定位、再验证恢复，最后形成可复用结论。

## 输入

- 事故现象与影响范围
- 当前环境与告警线索
- 已知变更和时间线

## 标准步骤

1. `@@TL` 定义优先级与止血目标。
2. `@@BE` 与 `@@DEVOPS` 联合定位根因线索。
3. `@@BA` 判断是否涉及边界或系统性风险。
4. `@@BE` 提交修复动作，`@@DEVOPS` 执行恢复验证。
5. `@@TL` 决策恢复/阻塞/回滚并安排复盘。

## 输出

- 事故影响说明
- 根因与修复动作
- 恢复验证结果
- 后续治理建议

## 门禁规则

- 未止血前不得扩散改动范围。
- 恢复动作未验证不得宣告恢复完成。
- 超过 2 轮仍无法恢复，交用户决策。
