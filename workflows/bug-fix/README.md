# 缺陷修复

## 目标

定位缺陷、快速修复、验证关闭并控制回归风险。

## 输入

- 缺陷现象与复现条件
- 影响范围和风险等级
- 相关代码与日志线索

## 标准步骤

1. `@@BE` 复现问题并定位根因。
2. `@@BA` 判断是否涉及边界或架构风险。
3. `@@BE` 提交修复方案和断言更新。
4. `@@DEVOPS` 执行修复后验证并反馈实际结果。
5. 必要时循环修复-复测，`@@TL` 最终决策。

## 输出

- 根因说明
- 修复动作
- 验证结果
- 风险与回滚建议

## 门禁规则

- 未复现或根因不明不得宣告修复完成。
- 修复后未验证不得关闭。
- 修复-复测超过 2 轮仍失败，交用户决策。
