# 设计到编码

## 目标

把设计方案转成可实现、可验证、可回滚的编码任务。

## 输入

- `@@TL` 设计阶段结论
- `@@BA` 边界与风险结论
- 相关模块与依赖链路

## 标准步骤

1. `@@BE` 拆分实现任务和变更范围。
2. `@@BE` 输出断言清单（验证项/期望值/失败判定）。
3. `@@BA` 复核是否越过边界。
4. `@@DEVOPS` 确认验证路径是否可执行。
5. `@@TL` 确认是否进入实现执行。

## 输出

- 实现任务清单
- 断言清单
- 风险与兼容说明
- 进入实现阶段结论

## 门禁规则

- 无断言清单不得进入实现。
- 越边界改动未获 BA/TL 确认不得进入实现。
- 分歧超过 2 轮无收敛，交用户决策。
