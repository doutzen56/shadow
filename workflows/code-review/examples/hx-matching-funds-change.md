# HX.Matching 资金与订单状态审查案例

## 适用场景

用于审查涉及金额、余额、手续费、订单状态、回调、渠道状态映射和撮合结果的改动。

## 审查优先级

资金和订单状态属于高风险区域。审查时应优先找行为错误、状态不一致、幂等缺失和回归风险，而不是只看代码风格。

## 必查问题

1. 是否改变订单状态流转。
2. 是否改变金额、手续费、余额或汇率计算。
3. 是否影响商户订单号、平台订单号或幂等规则。
4. 是否影响回调通知和重试。
5. 是否影响查单接口返回。
6. 是否影响后台人工处理。
7. 是否影响统计、报表或搜索索引。
8. 是否影响异步任务和消息消费者。

## 重点链路

- 商户代收下单到收银台。
- 商户代付下单到出款结果。
- 合作方下单到收款账户匹配。
- 渠道回调到订单状态推进。
- 订单超时到最终状态。
- 回调商户或合作方。

## 测试建议

- 正常成功路径。
- 渠道返回失败。
- 渠道返回处理中。
- 重复回调。
- 查单与回调状态一致性。
- 超时后再收到回调。
- 人工处理后再收到异步消息。
