# 项目初始化

## 目标

让新项目在进入执行前完成档案映射、环境就绪和边界确认。

## 输入

- 工作区名称/仓库名称
- 对应项目档案路径
- 目标环境（`dev/test/uat`）

## 标准步骤

1. `@@X` 触发 `simpx-project-bootstrap` 进行基础检查。
2. 校验项目档案：`README.md`、`profile.yaml`、`boundaries.md`。
3. 校验环境文件：`envs.yaml` 与本地 secrets 配置。
4. `@@TL` 确认初始化结果与后续任务入口。

## 输出

- 初始化检查结果
- 缺口清单
- 是否可进入功能开发

## 门禁规则

- 项目映射不清或关键档案缺失，不进入开发。
- 环境配置不可用，不进入验证阶段。
- 初始化争议超过 2 轮未收敛，交用户决策。
